# Security Testing Scope

This project is an isolated educational sandbox for the Sciencia AI Cyber Security Internship.

## In scope

- Reading and reviewing the code in this repository
- Running the application on your own local machine
- Mapping the architecture and data flow
- Reviewing configuration, storage, logging, dependencies, authentication/authorization assumptions, and input handling
- Later, if explicitly requested, validating findings against your local copy of the sandbox

## Out of scope

- Testing any Sciencia AI production system
- Testing any client system
- Testing the public websites or APIs of third parties
- Scanning, probing, exploiting, or bypassing controls on external services
- Using credentials or data that are not included in this sandbox

If you are unsure whether an activity is permitted, stop and ask before proceeding.
