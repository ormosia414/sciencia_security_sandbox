# Student Start Here

For the first module, do **not** begin active security testing.

Your first deliverable should focus on understanding the system. Review the repository and run the application locally if helpful, then document:

- a simple architecture / data-flow diagram;
- the main components, data stores, external/provider boundary, and access points;
- the main assets that need protection;
- where configuration, logs, and stored data live;
- the trust boundaries you identify;
- an initial list of security questions or risk areas that deserve closer review.

Keep the work in a **private GitHub repository**. Do not include real credentials, client information, or any external system data.

Send the repository link and a short summary when the first module is complete.
